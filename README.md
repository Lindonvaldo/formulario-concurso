# Formulário de Inscrição para Concurso

## Projeto desevolvido em Python

Este progroma simula uma inscrição para concurso público

## Funcionalidades

- Cadastro do candidato; 
- Validação de idade;
- Escolha da escolaridade;
- Escolha da área profissiona;
- Uso de comandos condicionais;

## Tecnologias utilizadas 

- Python 3
- VS Code
- Git 
- Github
